# REFILL FESTA STAMP TOUR — 스태프 사용 설명서

> 리필페스타 팝업스토어 현장 스태프·경품 교환 담당자용  
> **서비스 주소** · [https://refeel-festa-stampweb.web.app/](https://refeel-festa-stampweb.web.app/)

---

## 1. 이 시스템은 무엇인가요?

방문객이 **앱 설치 없이** 스마트폰 카메라로 부스 QR을 스캔하면, 웹에서 스탬프가 자동으로 적립됩니다.  
**4개 부스 중 3개 이상** 스탬프를 모은 방문객에게 경품을 지급하고, 수령 후에는 **같은 기기로 다시 참여할 수 없도록** 화면이 잠깁니다.

| 항목 | 내용 |
|------|------|
| 앱 설치 | **불필요** |
| 회원가입 | **불필요** (자동 익명 로그인) |
| 스태프 역할 | 경품 교환 확인 · 암호 입력 · 도장 오류 시 안내 |

---

## 2. 행사 규칙 (꼭 숙지)

1. 방문객은 **4개 부스**를 돌며 스탬프를 수집합니다.
2. 스탬프 **3개 이상**이면 하단 **「경품 교환하기 (조건 충족)」** 버튼이 켜집니다.
3. 스태프가 스탬프 개수를 **눈으로 확인**한 뒤, **스태프 전용 4자리 암호**를 입력해야 경품 수령이 완료됩니다.
4. 경품 수령이 끝나면 **「경품 수령이 완료된 기기입니다」** 화면으로 바뀌며, **같은 폰으로는 재참여 불가**합니다.

> 스태프 암호는 운영팀에서 **별도로 전달**합니다. 이 문서·SNS·게시물에 올리지 마세요.

---

## 3. 부스 구성 (4섹션)

| 섹션 | 부스명 | QR 파라미터 |
|------|--------|-------------|
| SECTION 1 | 감정 하나 볼펜 하나 | `?section=1` |
| SECTION 2 | 나의 감정 트럭: Crush ! | `?section=2` |
| SECTION 3 | 수뭉이의 행복 충전소 | `?section=3` |
| SECTION 4 | 기록, 감정 보관소 | `?section=4` |

방문객 화면 하단 **「현재 진행률」** 에 `n / 4` 로 적립 개수가 표시됩니다.

---

## 4. 방문객 정상 참여 흐름

```
부스 QR 스캔 → 웹 열림 → 「인증 성공!」 팝업 → 메인 화면에 도장 표시
       ↓
3개 이상 모음 → 「경품 교환하기」 버튼 활성화
       ↓
경품 교환소 이동 → 스태프 확인 → 암호 입력 → 체험완료 화면
```

### 방문객에게 이렇게 안내하세요

1. **카카오톡·인스타 인앱 브라우저 말고**, **스마트폰 기본 카메라**로 QR을 스캔해 주세요.
2. QR 스캔 후 **「인증 성공!」** 이 뜨고, 해당 부스 칸에 **도장 이미지**가 보이면 성공입니다.
3. 이미 찍은 부스를 다시 스캔하면 **「이미 완료된 부스입니다」** 가 잠깐 뜹니다. (정상)
4. 스탬프 **3개 이상**이면 **「경품 교환하기 (조건 충족)」** 버튼을 눌러 경품 교환소로 와 주세요.

---

## 5. 경품 교환 절차 (스태프 핵심)

### Step 1 — 스탬프 확인

방문객 폰의 메인 화면에서 아래를 확인합니다.

- [ ] 하단 진행률 **3 / 4 이상** 인지
- [ ] 도장이 찍힌 부스 칸에 **완료 이미지**가 보이는지 (빈 `STAMP HERE!` 원이 아닌지)
- [ ] **「경품 교환하기 (조건 충족)」** 버튼이 보이는지

### Step 2 — 암호 입력

1. 방문객이 **「경품 교환하기 (조건 충족)」** 버튼을 누릅니다.
2. **「스태프 확인」** 창이 열립니다.
3. **스태프가 직접** 운영팀에서 받은 **4자리 암호**를 입력합니다.  
   (방문객에게 암호를 알려주지 마세요. 스태프가 입력하거나, 스태프 앞에서만 입력하게 하세요.)
4. **「확인」** 을 누르면 경품 수령 처리가 완료됩니다.

### Step 3 — 체험완료 화면 확인

아래 화면이 나오면 **경품 지급 OK** 입니다.

- 상단 배너: **「경품 수령이 완료되었습니다」**
- 중앙: **체험완료 도장** 이미지
- 문구: **「경품 수령이 완료된 기기입니다」**
- 하단: **실시간으로 움직이는 시계** (고정 스크린샷과 구분용)

> 이 화면이 보이지 않으면 아직 경품 수령 처리가 안 된 것입니다. 경품을 주지 마세요.

### 암호를 잘못 입력한 경우

- **「비밀번호가 틀렸습니다」** 알림이 뜹니다.
- 다시 올바른 암호로 입력하면 됩니다. 스탬프는 그대로 유지됩니다.

## 6. 도장이 안 찍힐 때 (트러블슈팅)

| 증상 | 확인·조치 |
|------|-----------|
| QR 스캔 후 아무 반응 없음 | Wi‑Fi/ LTE 연결 확인. 페이지 새로고침 후 QR **다시 스캔** |
| 「도장 적립에 실패했습니다」 | 네트워크 불안정. 잠시 후 **같은 QR 재스캔** |
| 「이미 완료된 부스입니다」 | 이미 해당 부스 도장 있음. **정상** — 다음 부스 안내 |
| 도장이 안 찍힌 것 같음 | 메인 화면 해당 칸에 도장 이미지 있는지 확인 |
| 인앱 브라우저(카톡 등)에서 안 됨 | **사파리·크롬** 등 기본 브라우저에서 QR 스캔 안내 |
| 시크릿(비공개) 모드 | 일반 브라우저 사용 안내 (세션이 유지되지 않을 수 있음) |

### 수동 URL 백업 (QR이 계속 안 될 때만)

QR 스캔이 반복해서 실패할 때, 스태프가 방문객에게 **아래 링크 중 해당 부스 것**을 눌러 달라고 안내할 수 있습니다.

| 부스 | 수동 링크 |
|------|-----------|
| SECTION 1 | https://refeel-festa-stampweb.web.app/?section=1 |
| SECTION 2 | https://refeel-festa-stampweb.web.app/?section=2 |
| SECTION 3 | https://refeel-festa-stampweb.web.app/?section=3 |
| SECTION 4 | https://refeel-festa-stampweb.web.app/?section=4 |

**사용 방법**

1. 방문객 폰에서 위 링크를 **터치**합니다. (카톡으로 보내서 눌러도 됩니다.)
2. **「인증 성공!」** 이 뜨고 도장이 찍히면 완료입니다.
3. 링크는 **해당 부스를 실제로 방문한 경우에만** 안내하세요.

> 수동 링크는 **오류 대응용**입니다. SNS·현장 게시물에 대량 공개하지 마세요.

## 7. 자주 묻는 질문 (FAQ)

**Q. 스탬프 2개만 있는데 경품을 달라고 합니다.**  
A. 규칙상 **3개 이상** 필요합니다. 「경품 교환하기」 버튼이 안 보이면 지급하지 마세요.

**Q. 친구 폰으로 대신 받을 수 있나요?**  
A. 스탬프·경품 모두 **그 폰에 묶입니다**. 본인 폰으로 참여·수령 원칙을 안내하세요.

**Q. 경품 받은 뒤 다시 참여하고 싶다고 합니다.**  
A. **불가**합니다. 체험완료 화면이 잠금 역할을 합니다.

**Q. 폰을 바꿨는데 스탬프가 없어졌어요.**  
A. 스탬프는 **기기·브라우저 세션**에 연결됩니다. 폰을 바꾸면 처음부터입니다. (운영 정책에 따라 현장 판단)

**Q. 같은 부스 QR을 여러 번 찍었어요.**  
A. 도장은 **1번만** 적립됩니다. 중복 스캔은 안내 토스트만 뜹니다.

**Q. 암호를 잊었어요.**  
A. **운영팀**에 문의하세요. (현장 스태프끼리 공유 메모에 적어 두되, 방문객에게 보이지 않게 관리)

## 8. 스태프가 하지 말아야 할 것

- 스태프 암호를 **방문객·SNS·게시물**에 공개하지 않기
- 스탬프 **3개 미만**인데 경품 지급하지 않기
- 체험완료 화면 **없이** 경품 지급하지 않기
- 수동 URL(`?section=`)을 **부스 방문 없이** 임의로 대량 안내하지 않기
