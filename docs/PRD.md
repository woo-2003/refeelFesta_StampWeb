> 상명대 리필페스타 팝업스토어 웹 스탬프 투어 기획 문서

## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| **행사명** | 리필페스타 팝업스토어 |
| **서비스명** | REFILL FESTA STAMP TOUR (신촌랩소디) |
| **목적** | 부스 체험 유도 및 회차 완주율 향상 |
| **접속 방식** | 부스 QR 코드 스캔 → 모바일 웹 즉시 접속 (앱 설치 불필요) |

### 핵심 규칙: 4개 중 3개 수령

- 방문객은 **4개 부스**를 순회하며 스탬프를 수집한다.
- **스탬프 3개 이상** 수집 시 **[경품 교환하기]** 버튼이 활성화된다.
- 스태프 인증 후 경품 수령이 완료되면 화면이 **체험완료 잠금 상태**로 전환된다.

### 부스 구성 (4섹션)

| 섹션 | 부스명 | 배경 컬러 |
|------|--------|-----------|
| 1 | 감정 하나 볼펜 하나 | 연분홍 `#f6f1f4` |
| 2 | 나의 감정 트럭: Crush ! | 진분홍 `#ecc4cd` |
| 3 | 수뭉이의 행복 충전소 | 연하늘 `#d7eef9` |
| 4 | 기록, 감정 보관소 | 진하늘 `#b7d6f1` |

## 3. 사용자 플로우

### 3.1 QR 스캔 → 스탬프 적립

1. 사용자가 스마트폰 카메라로 부스 QR 코드를 스캔한다.
2. `?section=n` 파라미터와 함께 웹앱에 진입한다.
3. Firebase 익명 UID가 발급·유지된다.
4. Firestore에서 해당 섹션 적립 여부를 확인한다.
   - **미적립**: `section_n: true` 업데이트, 스탬프 카드에 도장 활성화
   - **중복 스캔**: "이미 완료된 부스입니다." 토스트 알림

### 3.2 메인 화면 (스탬프 카드)

- 상단: SinchonRhapsody 폰트 적용 메인 타이틀
- 중앙: 4칸 원형 스탬프 카드 레이아웃
- 하단: 진행률 표시 (`n / 4`) 및 **[참여방법안내]** 버튼

### 3.3 참여방법안내 모달

> "스마트폰 기본 카메라 앱을 실행하여 부스에 비치된 QR 코드를 스캔하면 도장이 자동으로 적립됩니다."

### 3.4 경품 교환 (스태프 암호)

1. 스탬프 **3개 이상** 수집 시 **[경품 교환하기]** 버튼 활성화
2. 버튼 클릭 → 스태프 4자리 암호 입력 모달 노출
3. 암호 검증
   - **실패**: 경고 알림 후 재입력
   - **성공**: Firestore `isClaimed: true` 업데이트 → 체험완료 화면 전환
4. 체험완료 화면: 중앙 **체험완료 수뭉 도장** + 백그라운드 **실시간 타이머** (스크린샷 어뷰징 방지)

> **운영 참고**: 스태프·개발자 암호는 `.env.local`에서 관리하며 Git 저장소에는 포함하지 않는다. 변경 시 재빌드·재배포가 필요하다.

## 4. 개발자 리셋 기능 (숨김)

현장 오프라인 테스트 및 오류 복구를 위한 관리자 전용 기능이다.

| 항목 | 내용 |
|------|------|
| **트리거** | 체험완료 화면 상단 타이틀 영역을 **5회 연속 탭** |
| **인증** | 개발자 전용 암호 입력 (`VITE_DEV_RESET_PASSWORD`, 저장소 미포함) |
| **동작** | 해당 UID의 Firestore 문서 초기화 (`stamps` 전부 `false`, `isClaimed` → `false`) |

## 5. 예외 처리 가이드

| 시나리오 | 처리 |
|----------|------|
| 인앱 브라우저 세션 끊김 | Firebase 익명 토큰으로 DB에서 상태 복구 |
| 동일 QR 중복 스캔 | 연산 생략 + 토스트 알림 |
| 시크릿 모드 접속 | 전면 차단막 + 일반 브라우저 안내 |
| URL 파라미터 위변조 (`?section=99`) | 에러 팝업 후 메인으로 리다이렉트 |
| 네트워크 수신 불량 | 5초 timeout 후 [다시 시도하기] 모달 |
| 브라우저 데이터 강제 삭제 | 오프라인 검증(입장권 구멍·손등 도장) 연계 |
| 스태프 암호 유출 | `.env.local`에서 암호 변경 후 재빌드·재배포 |
